# Fonts

`bricolage-grotesque.woff2` is the latin subset of **Bricolage Grotesque**, a
variable font (weight 200–800, optical size 12–96), taken from Google Fonts.

It is stored here rather than linked from `fonts.googleapis.com` so the page
makes no request off its own origin: type is there on the first paint of an
offline or locked-down browser too, and no third-party CDN can change or fail
underneath the product. `docs/styles.css` declares it and `docs/index.html`
preloads it.
