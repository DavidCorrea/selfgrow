Syntax Reference

Formal grammar for the selfgrow language, described in EBNF notation. The grammar is derived from the interpreter's parser and reflects all registered keywords, operators, and syntactic forms.

Tokens

The tokenizer produces the following token types from source text.

TypePatternDescription
number [0-9]+ ('.' [0-9]+)? ([eE][+-]?[0-9]+)? Integer, decimal, or scientific notation
string "..." Double-quoted string with escape sequences: \" \\ \n \t \r
boolean true false Boolean literal keywords
identifier [a-zA-Z_][a-zA-Z0-9_]* Variable names, function names, field names
keyword see keywords below Reserved words that are not identifiers
operator see operators below Arithmetic, comparison, logical, and concatenation operators
punctuation see punctuation below Grouping, sequencing, and record syntax characters
eof — End of input

Keywords

The following identifiers are reserved as keywords and cannot be used as variable or function names.

  • let
  • in
  • if
  • then
  • else
  • end
  • while
  • do
  • fn
  • letrec
  • true
  • false
  • nil
  • and
  • or
  • not

Keywords true, false, nil, and, or, and not are registered by the boolean capability and also function as operators in their respective contexts.

Operators

Operators are registered by capabilities and have associated precedence and associativity rules.

Arithmetic

  • + addition (precedence 10, left)
  • - subtraction / unary minus (precedence 10, left / prefix)
  • * multiplication (precedence 20, left)
  • / division (precedence 20, left)

Comparison

  • == equality (precedence 5, left)
  • != inequality (precedence 5, left)
  • < less than (precedence 5, left)
  • > greater than (precedence 5, left)
  • <= less than or equal (precedence 5, left)
  • >= greater than or equal (precedence 5, left)

Logical

  • or logical or (precedence 2, left)
  • and logical and (precedence 3, left)
  • not logical not (prefix, unary)

String

  • ++ string concatenation (precedence 10, left)

Other

  • = binding / assignment in let/letrec
  • = function definition arrow (after params)
  • => reserved two-character operator token

Operator precedence (highest to lowest): * / / (20) > + - (10) > == != < > <= >= (5) > and (3) > or (2). Prefix unary minus has higher precedence than binary operators.

Punctuation

  • (
  • )
  • {
  • }
  • ,
  • ;
  • [
  • ]
  • :
  • #
  • .

# introduces a record literal. . is used for field access (dot notation). ( and ) are used for grouping expressions and function call argument lists.

Grammar (EBNF)

The following grammar rules describe the full syntax of the selfgrow language. Non-terminals are shown in italic (monospace). Terminals are quoted.

Program Structure

program ::= statement* statement ::= letStmt | ifStmt | whileStmt | fnDef | doBlock | letrecStmt | exprStmt exprStmt ::= expr block ::= statement*

Statements

letStmt ::= let IDENTIFIER [= expr] in expr ifStmt ::= if expr then expr [else expr] end whileStmt ::= while expr do block end fnDef ::= fn IDENTIFIER ( [paramList] ) = expr doBlock ::= do expr* end letrecStmt ::= letrec IDENTIFIER = expr in expr

Expressions

expr ::= orExpr orExpr ::= andExpr { or andExpr } andExpr ::= notExpr { and notExpr } notExpr ::= not notExpr | comparisonExpr comparisonExpr ::= addExpr { (== != < > <= >=) addExpr } addExpr ::= mulExpr { (+ -) mulExpr } mulExpr ::= unaryExpr { (* /) unaryExpr } unaryExpr ::= - unaryExpr | prefixOp unaryExpr | primary primary ::= number | string | true | false | nil | ( expr ) | # { [fieldList] } | IDENTIFIER { callSuffix | fieldSuffix } | fn ( [paramList] ) = expr | ifExpr | letrecExpr ifExpr ::= if expr then expr [else expr] end letrecExpr ::= letrec IDENTIFIER = expr in expr callSuffix ::= ( [argList] ) fieldSuffix ::= . IDENTIFIER argList ::= expr { , expr } fieldList ::= IDENTIFIER : expr { , IDENTIFIER : expr } paramList ::= IDENTIFIER { , IDENTIFIER }

Comments

comment ::= // { any character except newline }

Functions

Records

get(#{name: "x", value: 42}, "name") → x

Lists

Higher-Order List Operations

Recursive Functions (letrec)

letrec factorial = fn(n) = if n <= 1 then 1 else n * factorial(n - 1) end in factorial(5) → 120
letrec fib = fn(n) = if n <= 1 then n else fib(n - 1) + fib(n - 2) end in fib(10) → 55
